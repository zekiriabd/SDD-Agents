# rules/ — ce que chaque agent DOIT ou NE DOIT JAMAIS faire

Un fichier Markdown par règle de comportement déclarée au roster (`{rule}.md`,
slug en kebab-case) : la contrainte, sa raison (la BR de la MISSION qu'elle
porte), et l'observable qui prouve qu'elle est tenue. Citée sous `## Règles` de
`../prompts/{agent}.system.md`.

Une règle n'a ni schéma ni gate propre : elle se mesure par les AC des CAPs que
l'agent sert (G5), jamais par un contrôle isolé.
